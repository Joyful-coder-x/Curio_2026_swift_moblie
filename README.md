# Curio_2026_swift_moblie
Curio is an iOS app concept for noticing everyday discoveries, sharing photo invitations, and keeping a shared journal.

## Concept proposals

- [English](docs/English/Match_Me_Concept_Proposal_EN.docx)
- [Chinese / 中文](docs/Chinese/Match_Me_Concept_Proposal_ZH.docx)

The original proposals use the working name **Match Me**. Their contents are preserved unchanged.

Swift and SwiftUI are the intended implementation tools. This repository currently contains the concept proposals.
